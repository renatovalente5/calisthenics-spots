Privacidade

Versão curta: não há cookies, não há publicidade, não há contas, não há estatísticas de visitas, e a tua localização nunca sai do teu aparelho.

Não há cookies e não há banner

Este site não instala cookies e não corre nenhuma ferramenta de análise de tráfego — nem Google Analytics, nem alternativas ditas «amigas da privacidade». Por isso não verás aqui um aviso de cookies a pedir consentimento: não há nada para consentir. Um banner num site que não usa cookies seria teatro.

A tua localização

Quando carregas em «Perto de mim» ou no botão de localizar, o teu navegador pede-te permissão e, se aceitares, dá as tuas coordenadas à página que está aberta no teu aparelho. Essa coordenada é usada ali mesmo, no teu telemóvel ou computador, para calcular a que distância ficam os sítios e para ordenar a lista.

Não é enviada para nenhum servidor. Não vai num endereço, num formulário nem num pedido de rede. Não é guardada. Se fechares a página, desaparece.

Nunca pedimos a localização sozinhos: só depois de carregares no botão. Se recusares, o site funciona na mesma — procuras pelo nome do concelho.

O que fica guardado no teu navegador

Uma única coisa, e só se a escolheres: a tua preferência de tema claro ou escuro, guardada no armazenamento local do navegador com a chave bf:tema. Fica no teu aparelho, nunca é enviada para lado nenhum, e desaparece se limpares os dados do site. Se nunca carregares no botão do tema, nada é guardado.

O que o teu navegador contacta

Para desenhar o mapa, o teu navegador vai buscar os mosaicos a OpenFreeMap (tiles.openfreemap.org). Como em qualquer imagem carregada de outro domínio, esse servidor vê o endereço IP do teu aparelho — é assim que a internet funciona, não é uma escolha nossa de recolher nada. Se ficares só na lista e nunca abrires o mapa, os mosaicos não chegam a ser pedidos.

Tudo o resto — a folha de estilos, o código, a biblioteca do mapa e o ficheiro com os sítios — é servido deste mesmo site. Não há CDN de terceiros, não há tipos de letra do Google, não há widgets sociais.

O botão «Como chegar» é uma ligação normal para o Google Maps (ou para o Apple Maps). Nada é carregado do Google dentro desta página; só sais daqui se carregares, e a partir daí aplicam-se as regras de privacidade deles.

Registos do alojamento

O site está alojado no GitHub Pages. Como qualquer servidor web, o GitHub regista os pedidos que recebe, incluindo endereços IP, para operar e proteger o serviço. Isso é feito pelo GitHub e não temos acesso a esses registos nem os usamos. Ver a declaração de privacidade do GitHub.

Direitos e contacto

Não sendo recolhido nenhum dado pessoal por este site, não há nada para consultar, corrigir ou apagar. Ainda assim, se tiveres uma dúvida ou quiseres reportar um problema, abre um assunto no repositório do projecto.

Aviso sobre o equipamento

Os sítios listados aqui não são nossos. Não os construímos, não os inspeccionamos e não os mantemos — são, na maioria, equipamento público dos municípios. A informação vem do OpenStreetMap e pode estar desactualizada ou errada: um parque pode ter fechado, e uma barra pode estar partida. Verifica sempre o estado do aparelho antes de o usares e não treines em equipamento danificado. Se encontrares algo partido, avisa a câmara municipal.

Alterações

Se algum dia isto mudar — por exemplo, se o site passar a ter publicidade ou donativos —, esta página é actualizada antes da mudança entrar em vigor, e passará também a ser obrigatório publicar aqui a identificação completa do responsável. Hoje não é o caso.
